# 胡金铨 风格档案

> 代表作：《大醉侠》(1966)、《龙门客栈》(1967)、《侠女》(1971)、《迎春阁之风波》(1973)、《忠烈图》(1975)、《空山灵雨》(1979)、《山中传奇》(1979)

## 一句话定位

**一幅会动的中国画。** 武侠只是题材，真正的内容是山水、禅意和人在天地间的位置。人物从属于自然，常常只占画面一隅。

## 三个底子

理解这三样，才知道每个画面选择的出处：

1. **国画**——家学渊源，本人是书法家和水彩画家。带来：手卷式的横向展开、留白、三远法、以线造型、虚实相生。
2. **京剧**——武打身段、亮相、锣鼓点式的剪辑节奏、程式化的角色造型。带来：人物的姿态是"摆出来的"，有雕塑感，不是自然主义的。
3. **明史考据**——服装从故宫藏的锦衣卫千户画像翻制，造型参考《王蜀宫妓图》《摹唐卢眉娘像》。带来：画面里每样东西都有出处，没有想当然的"古装感"。

## 构图法则

### 核心原则：人小、天大、景满

- 人物在全景中常只占画幅的 **1/8 到 1/6**，靠姿态和衣色识别，不靠脸。
- 大面积留白，通常给天空、雾气或岩壁。**留白不是空，是构图的一部分**。
- 画面重心极少在正中。正中对称只用在极少数仪典性场面（佛殿、堂审）。

### 七种常用构图

详细的镜头范式和现成模板见 `shots.md`，这里只给辨识特征：

| 构图 | 特征 | 用途 |
|---|---|---|
| 三分 | 人物压在一侧三分线上，另外三分之二给山雾 | 独行、孤绝 |
| 对角线 | 多人沿一条斜线阶梯式错落排布 | 行进中的小队、以斜造势 |
| 对立 | 左右两组人分踞画面两端，中间空出对峙地带 | 正邪对峙，常配色彩对冲 |
| 三角 | 三人或多人构成稳定三角，主角在顶点或前景底角 | 群像、主次分明 |
| 框架 | 用树干、门洞、山岩、窗棂在画内再造一个框 | 把远处的小人物框出来，压迫感 |
| 环绕 | 一圈人围住中心，摄影机在圈外，前景人物背对镜头 | 包围、瓮中捉鳖 |
| 手卷横摇 | 人物从画左入、向右行，山水横向铺开 | 行旅、定场、开篇 |

### 机位

- **低机位仰拍**是招牌：人物顶天，天空大面积留白，气场立刻起来（`gallery/03`）。
- **平视中远景**用于对峙和群像，保持空间关系清楚。
- **极少用俯拍压人**，除非要表现被围困。
- **画面允许轻微倾斜**（3–8 度），打破呆板，增加动势（`gallery/05`）。
- 人物常**从画面边缘入画或出画**，画面外仍有空间（"画外有画"）。

### 空间层次

必须**三层**：前景遮挡物 + 中景主体 + 远景山雾。

- 前景常用：虚焦的松枝、竹干、岩石边缘、人物背影的一角。
- **三远法**：同一画面里混合仰视的山（高远）、层叠后退的山脊（深远）、横向铺开的平地（平远）。不追求单一透视灭点。
- 空气透视做纵深：越远越淡、越偏冷、对比越低。远山几乎只剩一道轮廓。

## 光影

**自然光至上。** 本人会为了一道光等太阳走到位置，《侠女》竹林戏五分钟拍了 25 天。所以光永远是"天给的"，不是"打出来的"。

### 五种标志性光

| 光 | 做法 | 效果 |
|---|---|---|
| **强逆光** | 太阳在人物正后方偏上，人成剪影或半剪影，边缘一圈金边 | 佛光普照的神圣感（`gallery/06`） |
| **丁达尔光柱** | 林间雾气中射入的可见斜光柱，精准打亮对峙区域 | 舞台聚光的效果，但来源是自然（`gallery/07`） |
| **低反差漫射光** | 雾天、阴天，无明显投影，暗部不死黑 | 柔化边界，人景交融（`gallery/02`） |
| **侧逆光 + 浅焦** | 侧后方光，背景虚化成光斑 | 空灵、非现实 |
| **水面/雨面反光** | 阳光在水面碎裂闪烁 | 动感，打破静止 |

### 反差与曝光

- 整体**低到中反差**，暗部保留细节，不做硬派黑白分明。
- **允许高光过曝**（天空、雾、逆光边缘可以冲掉），这是胶片的特性，也是"空"的来源。
- 例外：戈壁荒漠戏（《龙门客栈》）反差高、光硬、影子重。

### 雾

雾是胡金铨的第一道具。用法：
- 切断山脊，制造层次
- 吃掉地面，让人像浮在空中
- 让光柱可见
- 覆盖画面下三分之一，把人托起来

## 色彩

**清冷，但层次饱满。** 低饱和是底色，靠一两处高纯度色点睛。

### 基础色域

| 类别 | 颜色 |
|---|---|
| 人物素服 | 月白、素白、米白、本白（未漂白的麻布色）、浅豆青 |
| 环境 | 青灰岩、松针绿、土黄、赭石、雾白、枯草黄 |
| 天空 | 淡青、灰蓝、过曝的白、黄昏的浅橘 |

### 点睛重色（面积严格控制，通常不超过画面 10%）

| 色 | 谁在用 |
|---|---|
| **明黄 / 赭黄** | 僧袍（`gallery/04`、`gallery/06`） |
| **大红 / 绛红** | 东厂首领披风、高阶僧人袈裟镶边 |
| **玄黑** | 东厂番子、锦衣卫（与黄僧形成明暗对立） |
| **石青 / 群青** | 官服、少数女装 |

### 色彩对立

最有力的一招：**画面左右两半用冷暖 / 明暗完全对立的两组色**，视觉上直接说明"这是两股势力"（`gallery/04`：左黄右黑）。

### 忌

- 忌高饱和，忌鲜艳
- 忌粉色、紫色、荧光色
- 忌统一色温的数码调色感，画面里要有冷暖并存

## 服装与材质

- **明代为主**。女装：短衣长裙，外罩长衫。男装：戏曲褶子简化而来，交领、宽袖、束腰。
- **用材质区分身份，不用颜色**：宋锦=富贵，藤席、粗麻=江湖浪子，绸=官家，僧袍是粗织。
- 造型**近乎白描**，极简，不堆纹样。纹样只出现在高阶角色的局部（袈裟边、披风里子）。
- **衣带、飘带、披风下摆**必须处理成被风吹动的状态——这是"动静相宜"的关键：山石静止，衣带飘动，画面就活了（`gallery/02`）。

### 标志性行头

斗笠（竹编，常带垂纱）、幞头 / 网巾、僧帽、书生方巾、包袱、褡裢、油纸伞、长衫、绑腿、布鞋、单刀 / 长剑 / 禅杖 / 拂尘、绳索、灯笼、经卷。

## 读人定意境（路由表）

画面里有具体人物时，**先读人，再定意境，最后才轮到构图**。四轴读法见 `references/workflow-portrait.md` 步骤 2.1，读出四个字之后查这张表：

| 气质画像 | 意境 | 角色位 | 范式 | 光 | 主色 |
|---|---|---|---|---|---|
| 静 收 沉 贵 | **孤峙** — 握权者独处，深不可测 | 督主 / 权臣 | 一式 三分留白 | 低反差漫射晨光，脸三分之二在阴影 | 冷青灰 + 墨黑，暗红点睛 |
| 静 收 明 贵 | **端凝** — 静观其变，不动声色 | 书生 / 文士 | 一式 三分留白 | 柔和侧光，面部受光均匀 | 青灰 + 米白 |
| 静 张 明 贵 | **威仪** — 俯瞰众生的庄严 | 高僧 / 主事者 | 五式 画中之框 | 强逆光，半剪影，边缘金光 | 明黄 + 赭红 + 冷青负空间 |
| 静 收 明 野 | **空寂** — 人在山中极小，出世 | 隐者 / 行脚僧 | 一式（人物压到 1/8） | 雾中侧逆光，浅焦 | 素白 + 雾白 + 淡青 |
| 静 收 沉 野 | **伺机** — 藏在暗处，窥视 | 番子 / 暗探 | 五式 画中之框（被框住即被窥视） | 林隙漏光，大面积暗部 | 玄黑 + 暗红 + 墨绿 |
| 动 收 沉 野 | **苍茫** — 长路无尽，风霜在身 | 老江湖 / 樵夫 | 七式 手卷横摇 | 明亮天光，中等反差 | 松绿 + 岩灰 + 米白 |
| 动 张 沉 野 | **锋锐** — 蓄势待发，杀气内收 | 侠客 / 刺客 | 一式（人物稍大、有动势） | 侧逆光，反差偏高，边缘冷白轮廓 | 素白 + 墨黑 |
| 动 张 明 野 | **洒脱** — 不羁，带三分醉意 | 醉侠 / 浪子 | 七式 手卷横摇 | 明亮自然光，斑驳树影 | 米白 + 藤黄 + 松绿 |

### 怎么用这张表

- **不用完美匹配**，取最接近的一行。四轴里对上三个就够。
- **在两行之间摇摆时，以「沉 ↔ 明」轴为准**——这个轴对光和色的影响最大，选错了整张图的调子就错了；「动 ↔ 静」只影响姿态和衣物飘动，改起来最便宜。
- **用户明确要某个意境时以用户为准**，但要说一句"你这张脸读出来是 X，你要的是 Y，我按 Y 做，可能会有点违和"。
- **意境定的不只是构图，更是光和色。** 表里后两列才是真正拉开意境的东西——同一个一式三分留白，配「低反差漫射 + 冷青灰」是孤峙，配「雾中侧逆光 + 素白」就成了空寂。构图只是骨架，光色才是气。

## 气韵怎么落地

"禅意""空灵"这类词本身不能写进描述。它们由这些**具体做法**生成：

| 想要的感觉 | 具体做法 |
|---|---|
| 空灵 | 人物占比 ≤1/8 + 雾占画面 1/3 + 大面积留白 + 低反差 |
| 苍茫 | 低机位仰拍 + 天空占 2/3 + 远山只剩轮廓 + 冷灰色调 |
| 神圣 | 强逆光 + 人物半剪影 + 可见光柱 + 仰拍 |
| 紧张 | 对立构图或环绕构图 + 中间留出空地带 + 所有人静止不动 |
| 动静相宜 | 静止的山石 / 建筑 + 飘动的衣带 / 雾 / 幡 |
| 画外有画 | 主体被压在画面一侧，另一侧的空间"通向画外" |

## 禁忌清单

写完描述后逐条对照，命中就删：

**时代错位**
- 清代元素（辫子、马褂、旗装）——胡金铨是明代考据
- 日式元素（和服、鸟居、樱花、榻榻米、日式屋檐）——最容易串味的一类
- 任何现代物件（电线、玻璃、水泥、塑料、现代服装）

**色彩错位**
- 高饱和、鲜艳、霓虹、赛博朋克
- 粉色、紫色、荧光色
- 统一色温的数码感调色、HDR 泛滥

**构图错位**
- 主体居中特写占满画面
- 完全对称的呆板正面构图（仪典场面除外）
- 单层空间、没有前景遮挡
- 人物在全景中占比过大

**质感错位**
- 数码锐利感、塑料皮肤、3D 渲染感
- 过度磨皮、美颜、大眼瘦脸
- 浓妆、现代妆容、亮片、金属光泽

**动作错位**
- 夸张的 CG 特效、能量光效、火焰拖尾
- 网文修仙的飞剑御剑、法阵
- 慢镜头炫技式的飘浮

**内容越界**（实测最常犯）
- 用户没要求的配角、对手、围观群众、僧团、兵卒
- 用户没要求的冲突事件（对峙、围捕、打斗）
- 单人题材硬套群像范式
