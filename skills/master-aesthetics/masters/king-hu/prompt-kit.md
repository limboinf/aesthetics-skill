# 胡金铨 描述词库

组装描述时从这里取词。**别硬凑**——一段描述里每类取 2–4 个就够，堆多了互相稀释。

子风格（`variants.md`）定了的东西优先：比如选了龙门，光线就从"硬光"那一组取，别再从"雾"那一组取。

---

## 词库

### 构图 / 机位
三分构图、对角线构图、对立构图、三角构图、框架构图、环绕构图、手卷式横向构图 · 低机位仰拍、平视中远景、视平线压在画面下三分之一、画面轻微倾斜五度 · 人物只占画幅六分之一、人物压在右侧三分线上、大面积留白、天空占画面三分之二、主体偏离中心、从画面左缘入画、视线朝向画外 · 前景虚焦遮挡、三层纵深、多重视角并置、不追求单一透视灭点

### 光线
自然光、天光、高位散射光 · 强逆光、侧逆光、半剪影、边缘金色轮廓光 · 丁达尔光柱、林隙漏光、可见光束 · 低反差漫射光、无明显投影、暗部保留细节 · 高光轻微过曝、冲白的天空、柔和滚落的高光 · 浅景深、背景虚化成光斑 · 水面碎裂的反光 · 面部大半隐在阴影中、斗笠在眼部投下一道浅影
· 硬质正午光、短而黑的影子、白晃晃的天（荒原、海岸用）
· 门窗透进的天光、斜光柱里浮着尘、低位油灯、烛火只照亮半张脸、暗角里看得见木纹（室内用）
· 冷青月色、暗部不死黑、灯笼是唯一的暖点（夜用）
· 逆光里才看得见的雨丝、水洼反光、雨让远山发灰（雨用）

### 色彩
低饱和、清冷但层次饱满、冷暖并存 · 青灰、月白、素白、米白、未漂白的本白、浅豆青 · 松针绿、岩灰、土黄、赭石、枯草黄、雾白 · 淡青天空、灰蓝、过曝的白 · 点睛重色：明黄僧袍、赭黄、绛红袈裟、大红披风、玄黑劲装、石青官服 · 色彩对立：画面左半暖黄、右半玄黑
· 土黄、枯草黄、白晃晃的天（龙门）· 灰蓝海、湿黑礁石、沙色、芦苇黄（忠烈图）· 灰瓦、旧木、石灰白、苔绿（空山灵雨）· 秋叶赭红、藤黄、远山冷青（山中传奇）· 木褐、暗米白、宝蓝、织金（迎春阁）

> **写"夕阳"要限面积**（实测）：只写"黄昏、夕阳"，模型会把整片天铺成橙红，冲掉胡金铨的清冷底色。要写成"暖色只出现在夕阳附近和人物轮廓上，面积不超过画面五分之一，其余是雾青"。

### 质感 / 介质
七十年代彩色胶片质感、细腻胶片颗粒、轻微色偏、光晕与眩光、无锐化、柔和的高光滚落、粗织麻布、宋锦、藤席、竹编、风化的岩面、斑驳的木料、被雨水泡旧的墙

其他介质（褪色老拷贝、手绘分镜、水墨手卷、手绘海报）的第 6 段写法见 `variants.md` 末尾的介质表。

### 服装 / 人物
素白短衣长裙、交领长衫、戏曲褶子简化的宽袖袍、粗麻短打、绑腿布鞋 · 宽檐竹编斗笠、垂纱斗笠、幞头、网巾、书生方巾、僧帽 · 明黄僧袍、绛红袈裟、玄黑劲装配红腰带 · 束发、盘髻、包巾 · 衣带被风横向吹起、下摆翻起、飘带向反方向扬出
· 蓑衣、油纸伞（雨）· 明军布甲、头盔、披风（忠烈图）· 元代贵族袍服、毡帽（迎春阁）· 宋式幞头、襕衫、褙子、披帛（山中传奇）· 粗布短褂、总角（孩童）

> **深色交领容易画成日式**（实测）：深色交领短衣配系带，模型常画成日式作务衣。要写"宽袖、束布腰带"，并在负向里加"作务衣、和服式样"。

### 场景
荒野孤悬的两层木客栈、二楼回廊、方桌长凳 · 密集垂直的竹林、竹干如栅栏 · 之字形山道、悬空栈道 · 迷宫般的寺院回廊、经堂、佛塔、石阶、幡幢 · 虬曲古松与风化岩壁 · 空旷荒原、低地平线、风沙 · 断墙荒宅、蔓草、蛛网 · 层叠后退的山脊、谷底涌上的浓雾
· 乱石坡、枯草、黄土山道 · 礁石海岸、沙滩、芦苇荡、海边渔村 · 秋山、高原草坡、山间古堡、溪流石桥 · 客栈楼梯、二楼回廊、雅间、柜台

> **树林要写具体**（实测）：只写"密集的垂直树干"，模型默认画成排列整齐的北美针叶林，一眼出戏。东亚山林要点名：粗细不一、疏密不均、树干微微弯曲的杂木林 / 老松与阔叶混生 / 藤蔓垂挂 / 地面覆盖枯叶与蕨类。竹林同理，要写"竹干粗细不一、高低错落"。

### 道具
单刀、长剑、绣春刀、禅杖、拂尘、念珠、绳索、油纸伞、竹杖、包袱、褡裢、灯笼、经卷、长幡

### 气韵收尾句（挑一句，别叠）
山石静止，衣带飘动 · 人在山中极小 · 画外有画，言有尽而意无穷 · 围而未发，一触即发 · 虚实相生，层次分明 · 山水为主，人为点景 · 势均力敌，分庭抗礼 · 烈日之下，无处可藏 · 楼上楼下，各怀心思 · 似有若无，雾里有人 · 定在那一下，像戏台上的亮相

人物图追加：

```
换脸、五官变形、多人、双胞胎、年龄改变、网红脸
```

子风格追加：各子风格「最容易串成」那一条（见 `variants.md`）。

**单人画面必须追加**（实测：不写就会凭空长出配角）：

```
画面中只有一个人，不出现任何其他人物、配角、僧人、兵卒或围观者，没有背影、没有远处的人影
```

**双人画面追加**：

```
画面中只有两个人，不出现第三个人、配角或远处的人影
```

## 英文对照（改写给 Midjourney / Flux / SD 时用）

直译常常失效，按下表换成英文模型认得的说法。总的改写规则见 `references/model-adapters.md`。

| 中文 | 英文 |
|---|---|
| 留白 | large empty negative space, (sky / mist) fills two-thirds of the frame |
| 人小天大 | tiny figure in a vast landscape, figure occupies one-eighth of the frame |
| 三层纵深、前景遮挡 | layered depth: out-of-focus foreground branches, figure in midground, misty mountains behind |
| 三远法 | mixed perspectives: towering cliff, receding ridgelines, flat foreground slope in one frame |
| 雾吃掉地面 | mist swallows the ground, low clouds cut across the ridges |
| 丁达尔光柱、林隙漏光 | volumetric light shafts through the forest canopy, god rays in mist |
| 强逆光、半剪影、边缘金光 | strong backlight, half-silhouette, golden rim light |
| 低反差漫射光 | soft overcast diffused light, low contrast, no hard shadows |
| 高光轻微过曝 | slightly blown-out highlights, sky burned to white |
| 低饱和、清冷 | muted desaturated palette, cool grey-green tones |
| 点睛色 | a single small accent of saffron yellow / vermilion, under 10% of the frame |
| 七十年代彩色胶片 | 1970s 35mm color film still, fine film grain, soft halation, no digital sharpening |
| 褪色老拷贝 | faded release print, magenta color shift, light scratches and dust |
| 斗笠（垂纱） | wide conical bamboo hat (with a hanging gauze veil) |
| 交领宽袖长衫 | Ming dynasty cross-collar robe with wide sleeves, cloth sash |
| 粗麻短打、绑腿 | coarse hemp short jacket, leg wrappings, cloth shoes |
| 僧袍、袈裟 | saffron monk robe, crimson kasaya |
| 东厂番子玄黑劲装 | Ming secret police in black uniforms with red sashes |
| 亮相 | frozen Peking-opera pose, a held dramatic stance |
| 手卷横构图 | horizontal handscroll composition, figure walks left to right |
| 衣带被风吹起 | robe sashes fluttering sideways in the wind |
