# 胡金铨 镜头范式七式

每一式配一张 `gallery/` 里的参考图。模板里的 `<...>` 是占位符，**必须按题材改写后再交付**，不能原样给用户。

选式速查：

| 情境 | 用哪式 | 人数 |
|---|---|---|
| 一个人，孤绝、空灵 | 一式 三分留白 | **单人** |
| 一小队人在赶路 | 二式 对角行进 | 群像 3–5 |
| 两股势力对峙 | 三式 分庭对立 | 群像 6+ |
| 群像、有主有次 | 四式 三角群像 | 群像 3+ |
| 远处的人要被"框"出来 | 五式 画中之框 | **单人可，群像可** |
| 被包围、瓮中捉鳖 | 六式 环绕合围 | 群像 5+ |
| 开篇、定场、山水为主 | 七式 手卷横摇 | **单人可**，或 2–4 人 |

> ⚠️ 标"群像"的范式**会引入用户没要求的配角**。用户只给了一个人（一张单人照、或"一个侠客"这样的描述）时，只能用一式、五式、七式。见 SKILL.md 铁律 4。

## 一式 · 三分留白

**参考图** `gallery/02-thirds-mist-ribbon.webp`

**适用**：单人，孤绝、空灵、行至绝境。最常用的一式。

**要点**
- 人物压在左或右三分线上，占画幅 **1/6 – 1/8**
- 另外三分之二全给山体、雾气或天空
- 人物**朝向画面空的那一侧**（给视线留出去路），或背身
- 必有一样东西在动：衣带、斗笠系绳、发丝、飘幡
- 雾从下方涌上，吃掉地面，覆盖画面下三分之一

**默认光色**：低反差漫射光，青灰 + 米白，人物衣服是画面里最亮的一块。

**模板**
> 一名<身份>侧身立于<山岩/崖边/坡顶>，压在画面<右/左>侧三分线上，身形只占画幅约六分之一；<斗笠/头巾>压至眉际，面部大半隐在阴影里；<衣带/系绳>被风横向吹起，向画面<反方向>飘出。画面另外三分之二是<层叠的深色山体/陡峭岩壁>，山脚下浓雾由谷底涌上，切断山脊，覆盖画面下三分之一，人物像浮在雾上。前景是一道虚焦的深色<松枝/岩角>压住画面上缘。低反差漫射光，无明显投影，暗部保留细节，天空高光轻微过曝。整体青灰与米白低饱和色调，岩石偏冷灰，衣物是未漂白的本白，唯一略暖的是<斗笠的竹黄色>，面积极小。七十年代彩色胶片质感，细腻颗粒，高光柔和滚落。山石静止，衣带飘动，人在山中极小。

## 二式 · 对角行进

**参考图** `gallery/03-diagonal-low-angle-sky.webp`

**适用**：三到五人的小队在赶路、并肩而立、逆风前行。

**要点**
- 人头沿一条**对角线**从低到高（或反之）阶梯式错落排列
- **低机位仰拍**，天空占画面上半或 2/3，大面积留白
- 人物**不看镜头**，视线各自朝不同方向——制造"各有心事"
- 斗笠边缘互相叠压，形成节奏

**默认光色**：天光为主，淡青色天空，人物受柔和顶侧光；素白衣与深色衣交替排列。

**模板**
> <数量>名<身份>并肩<立于山脊/走在山道上>，低机位仰拍，视平线压在画面下三分之一处。<人物 A> 在画面左侧偏低，<人物 B> 居中略高，<人物 C> 在右侧最高，三人的头沿一条清晰的对角线阶梯式升高，斗笠边缘互相叠压。三人视线朝向各不相同，无人看向镜头。画面上方三分之二是<淡青色的空天空/几缕薄云>，大面积留白，衬得人物轮廓清晰。人物衣着为<素白短衣与玄色外褂交替>，斗笠是竹编本色，系带被风吹向同一侧。柔和的高位天光，低反差，面部受光均匀，斗笠在眼部投下一道浅影。整体低饱和，青白色天空、竹黄斗笠、素白与墨黑的衣料构成全部色彩。七十年代彩色胶片质感，细腻颗粒。以斜造势，人物虽静，画面有向前的动势。

## 三式 · 分庭对立

**参考图** `gallery/04-confrontation-yellow-black.webp`

**适用**：两股势力对峙，势均力敌，剑拔弩张但尚未动手。

**要点**
- 画面**左右两端各一组人**，中间空出一块无人的对峙地带
- 两组用**冷暖 / 明暗完全对立的两组色**（经典：左明黄僧袍 vs 右玄黑劲装）
- 两组人数可以不等，靠**视觉重量**平衡（人少的一方站在更亮或更高的位置）
- 每组内部**阶梯式排列**，不要站成一排
- 所有人**静止**，紧张感来自不动

**默认光色**：平光或高位自然光，两侧受光一致；背景是浅色岩壁，把深色人形衬出来。

**模板**
> 荒野<岩石峡谷/山坳>中两组人马对峙。画面左侧是<数量>名<明黄僧袍的僧人>，为首者身披<绛红袈裟>，站位略高，阶梯式错落排开；画面右侧是<数量>名<玄黑劲装的东厂番子>，束红腰带，佩绣春刀，整齐有序地一字排开，站位略低。两组之间空出画面中央三分之一的地带，无人踏入。背景是大面积浅灰黄的<风化岩壁>，把两组深浅对立的人形清晰衬出。所有人静止不动，没有任何动作，只有目光交汇。水平中远景，视平线在画面中部。高位自然光，光质偏硬，岩石上有明显的明暗分界，人物脚下有短促的投影。色彩上左半边是明黄与赭红的暖色块，右半边是玄黑与暗红的冷色块，中间的岩石是中性的灰黄，冷暖分庭抗礼。七十年代彩色胶片质感。势均力敌，一触即发。

## 四式 · 三角群像

**参考图** `gallery/05-triangle-group.webp`

**适用**：一群人，需要主次分明；结盟、议事、同行。

**要点**
- 主要人物构成一个**稳定三角**：一人在顶点（通常居中靠后且最高），两人在底角
- 次要人物填在三角内部和边缘，形成密度
- 画面**轻微倾斜 3–8 度**，打破呆板
- 景别：中景到中近景，能看清面部但不是特写
- 人物之间有**遮挡叠压**，制造纵深

**默认光色**：柔和自然光，低明暗反差，强化整体感；素白 + 赭黄 + 一点绛红。

**模板**
> <数量>名<身份>聚在<山岩前/寺门外/林中空地>，构成一个稳定的三角形：<核心人物>在画面中央偏后、位置最高，是三角的顶点；<人物 A>在画面左前方、<人物 B>在画面右前方，构成三角的两个底角。其余<数量>人填在三人之间的空隙里，头部高低错落，彼此有部分遮挡，形成前后纵深。画面整体轻微倾斜约五度，打破水平的呆板。中近景，能看清每个人的面部，但没有一张脸占据画面。背景是<质地粗糙的浅灰岩壁/斑驳的寺墙>，填满画面，不留天空。柔和的自然散射光，明暗反差低，每个人的面部都受光均匀，没有强烈投影，强化群体的整体感。色彩以素白衣、竹黄斗笠、灰岩为主，<核心人物的赭黄僧袍与绛红衣襟>是画面里唯一的重色，面积约十分之一。七十年代彩色胶片质感，细腻颗粒。人多而不乱，主次分明。

## 五式 · 画中之框

**参考图** `gallery/06-frame-backlight-forest.webp`

**适用**：远处的人物要被"框"出来；出场、揭示、神圣感。

**要点**
- 用**前景的树干 / 门洞 / 山岩 / 窗棂**在画面内再造一个框
- 被框住的人物**极小**，占画幅 1/10 以下
- 框是**深色剪影**，框内是亮的——明暗反差本身就是视线引导
- 常配**强逆光**：光源在被框人物的正后方，人成半剪影，边缘一圈光
- 大面积冷调负空间

**默认光色**：强逆光，暖金色光源 vs 冷青色阴影，雾气让光可见。

**模板**
> 密林中，前景左右两侧各有一株<粗大的深色树干>，上方枝叶垂下，在画面中央围出一个天然的<竖向/方形>框。框内远处的<山岩/坡顶>上站着<数量>名<身份>，身形极小，只占画幅十分之一，仅能辨认出<赭黄僧袍与绛红袈裟>的色块和轮廓。太阳在人物正后方偏上，强逆光穿过雾气与树隙，人物成半剪影，边缘镶一圈金色轮廓光。低机位仰拍，人物位于视平线之上。画面其余部分是大面积的冷青色阴影与雾气，构成负空间，占画面四分之三以上。整体色彩是冷青、墨绿与一道暖金光晕的对撞，低饱和，高光处大幅过曝冲白。七十年代彩色胶片质感，明显的光晕与眩光，颗粒细腻。人小而立于光中，画外有画，言有尽而意无穷。

## 六式 · 环绕合围

**参考图** `gallery/07-encircle-tyndall-forest.webp`

**适用**：被包围、瓮中捉鳖、围捕；也可用于仪式性的围观。

**要点**
- 一圈人**围住中心**，摄影机在圈外
- **前景必有一到两个背对镜头的人物**（通常只见背影和肩，虚焦或半虚），把观众放进包围圈里
- 中心的被围者**面积不大但最亮**
- 前中后**三层纵深**：前景背影 → 中层被围者 → 后层更多围拢的人和林木
- 密集的**垂直线**（树干、竹干、柱子）做天然栅栏，强化困局

**默认光色**：丁达尔光柱精准打在中心对峙区，四周偏暗；黄袍 + 青灰雾。

**模板**
> <林中/院落中>，<数量>名<身份>围成一圈，将中心的<被围者>困住。摄影机在包围圈之外：前景左右各有一名背对镜头的<身份>，只见背影、肩部与手中的<绳索/兵器>，处于半虚焦状态，把观者也放进这个包围圈里；中层是被围住的<被围者>，面向画面、手按<刀柄/兵器>，是画面里最亮的一点；后层还有更多人影和密集的<垂直树干>。背景的树干密集排列，形成天然的垂直栅栏，强化困局的压迫感。雾气弥漫，一束束丁达尔光柱从林梢斜射而下，精准打亮中心的对峙区域，四周则沉在阴影里。中景，平视机位。色彩以<赭黄僧袍>与青灰雾气为主，被围者的<绛红衣与蓝色条纹下裳>是全画唯一高纯度色。整体低饱和，光柱区域轻微过曝。七十年代彩色胶片质感。三层纵深，光如聚灯，围而未发。

## 七式 · 手卷横摇

**参考图** `gallery/01-travelers-pine-cliff.webp`

**适用**：开篇、定场、行旅；山水是主角，人只是点景。

**要点**
- **人物从画左入、朝画右行**（模拟看手卷的方向：右起左收，画中人反向行进）
- 山水**横向铺开**，画幅越宽越好（2.35:1）
- 人物在画面下三分之一，被巨大的自然包围
- **虬曲的古松**压住画面一角，这是最典型的前景
- 三远法：仰视的山壁 + 层退的远峰 + 横铺的近坡同框

**默认光色**：明亮的天光，中等反差；松绿 + 岩灰 + 米白衣。

**模板**
> 山道上，<数量>名行旅从画面左侧入画，朝画面右方行进，走在画面下三分之一处，身形只占画幅约<六分之一>。为首的<身份>手持<竹杖/长幡>，<身份>肩挑行囊，最后一人<身份>抬手指向右前方山外，视线引导观者向画右看去。三人都戴宽檐斗笠，<素白/米黄>长衫被风微微掀起。前景右上角是一株虬曲的<古松>，深绿针叶压住画面一角；中景是他们脚下的山道与岩石；远景是隔着雾的巨大<山壁/远峰>，只剩一层淡青色的轮廓。同一画面里同时有仰视的山壁、层层后退的远峰与横向铺开的近坡，多重视角并置，不追求单一透视。明亮的自然天光，中等反差，松针在人物身上投下斑驳的影子。色彩是松绿、岩灰、米白衣与竹黄斗笠，低饱和，远山泛冷青。2.35:1 宽画幅，七十年代彩色胶片质感。山水为主，人为点景，如展开一卷横幅山水。
