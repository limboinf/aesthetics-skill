# <大师中文名> 子风格与介质

`profile.md` 是共用的底子。这里每个子风格**只写和底子不一样的地方**。

- **子风格 = 一部作品的世界**：时代、地景、服装、整体色域、质感。一张图只有一个子风格。
- **意境 = 这一场戏的情绪**，在子风格的色域里变化。

3–8 个子风格。拉不开（地景、光、色三栏里不到两栏不同）就合并。
