# 怎么加一个新大师

加大师**只做两件事**：建一个目录，在 `SKILL.md` 的索引表加一行。主流程一个字都不用改。

## 步骤

### 1. 建目录

```bash
cp -r masters/_TEMPLATE masters/<代号>
```

代号用小写英文连字符：`king-hu`、`hayao-miyazaki`、`wong-kar-wai`、`hou-hsiao-hsien`。

### 2. 做调研

别凭印象写。至少覆盖这四类来源：

1. **代表作清单**——先确定哪几部片/哪批作品定义了这个风格，各自有什么视觉差异。
2. **影评与学术分析**——构图、机位、光影、色彩、剪辑的专门论述。中英文都搜，英文资料里的技术描述通常更精确。
3. **美术来源**——这位大师从哪来的？（胡金铨=国画+京剧+明史；宫崎骏=欧洲绘本+日本原风景；王家卫=杜可风+霓虹+广角）找到源头，风格档案才有骨。
4. **实际画面**——找 5–10 张有代表性的剧照，覆盖不同的构图类型。

**写之前先把画面看一遍。** 文字资料会漏掉最关键的视觉直觉。但剧照只用来调研，看完把读出来的东西写成文字，**图不放进数据包，文件里也不引用**——装这个 skill 的人手上没有这些图。

### 3. 填三个文件

| 文件 | 写什么 | 质量标准 |
|---|---|---|
| `profile.md` | 风格档案：定位、来源、构图法则、机位、光影、色彩、服装材质、场景母题、人物类型、**读人定意境路由表**、气韵落地表、**禁忌清单**、代表作速查 | 每个抽象词后面都跟着一个可执行的具体做法 |
| `shots.md` | 5–8 个镜头范式，每个写要点 + 默认光色 | **每一式都要标注人数**（单人可 / 群像 N+），否则单人题材会被套进群像范式、凭空造人 |
| `prompt-kit.md` | 分类词库 + 整段负向描述 | 词要可拆可组，每类给够选择余地 |

四条硬要求：

- **不放成品范例，也不放带占位符的整段模板。** 模型读到一段写好的描述，就会照着它的句式和意象去写，每张图都长得像那一段。数据包里只放规则、做法和词库，描述每次现写。
- **禁忌清单是最重要的一节。** 风格的辨识度来自"不做什么"。没有禁忌清单的数据包是废的——生图模型会默认往通用审美上跑。
- **气韵落地表必须有。** 把这位大师身上那些虚词（空灵、物哀、疏离、暧昧）逐个翻译成"占画幅几分之几""光从哪来""什么在动"。翻译不出来的虚词就别写进档案。
- **读人定意境路由表必须有。** 这位大师的世界里有哪几种意境？什么样的人配什么意境？每种意境对应的光和色是什么？没有这张表，人物类的需求只能靠拍脑袋选构图，出来的图会是"风格对了但人和画面两张皮"。

### 4. 注册

在 `SKILL.md` 的大师索引表加一行：代号、中文名、关键词（决定用户说什么话能命中）、数据包路径。

关键词要**写得宽**：既要有大师本名，也要有代表作名、风格标签、题材词。用户很少直呼大师名字，更多说"武侠意境""吉卜力那种""赛博霓虹雨夜"。

## 自检

新数据包做完，拿它跑一遍四条工作流各出一段描述（只用来自检，别存进数据包），然后问自己：

1. 把大师名字从描述里拿掉，还认得出是谁吗？
2. 这段描述和另一位大师的同题材描述，差异够大吗？
3. 禁忌清单能挡住最容易串味的那个风格吗？（中式古风串日式、吉卜力串迪士尼、王家卫串普通夜景）

三条都过了才算做完。
