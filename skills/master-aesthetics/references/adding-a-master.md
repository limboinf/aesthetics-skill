# 怎么加一个新大师

加大师**只做两件事**：建一个目录，在 `SKILL.md` 的索引表加一行。主流程一个字都不用改。

## 步骤

### 1. 建目录

```bash
cp -r masters/_TEMPLATE masters/<代号>
```

代号用小写英文连字符：`king-hu`、`hayao-miyazaki`、`wong-kar-wai`、`hou-hsiao-hsien`。

### 2. 做调研

别凭印象写。至少覆盖这四类来源：

1. **代表作清单**——先确定哪几部片/哪批作品定义了这个风格，各自有什么视觉差异。**这些差异就是子风格**：同一个导演，不同时期、不同题材的片子往往是不同的世界（王家卫的《东邪西毒》和《花样年华》、宫崎骏的《风之谷》和《龙猫》）。
2. **影评与学术分析**——构图、机位、光影、色彩、剪辑的专门论述。中英文都搜，英文资料里的技术描述通常更精确。
3. **美术来源**——这位大师从哪来的？（胡金铨=国画+京剧+明史；宫崎骏=欧洲绘本+日本原风景；王家卫=杜可风+霓虹+广角）找到源头，风格档案才有骨。
4. **实际画面**——找 5–10 张有代表性的剧照，覆盖不同的构图类型。

**写之前先把画面看一遍。** 文字资料会漏掉最关键的视觉直觉。但剧照只用来调研，看完把读出来的东西写成文字，**图不放进数据包，文件里也不引用**——装这个 skill 的人手上没有这些图。

### 3. 填五个文件

| 文件 | 写什么 | 质量标准 |
|---|---|---|
| `profile.md` | 所有子风格共用的底子：定位、来源、构图法则、机位、光影（含室内、时刻天气）、色彩、服装材质、场景母题、人物类型、**读人定意境三张表（单人 / 多人 / 无人）**、气韵落地表、时代处理、**禁忌清单**、影片速查 | 每个抽象词后面都跟着一个可执行的具体做法 |
| `variants.md` | **子风格**（3–8 个，每部 / 每期作品的世界：时代、地景、光、色、服装、质感、偏好范式、意境折算、禁忌增减、最容易串成）+ **介质表** | 只写和底子不一样的地方；每个子风格都要有「最容易串成」 |
| `shots.md` | 6–12 个镜头范式，每个写要点 + 默认光色 | **每一式都要标注人数**（单人可 / 2 人 / 群像 N+），并且单人、两人、人要看得清（头像）、室内这几种情况都要有可用的式 |
| `prompt-kit.md` | 分类词库 + 整段负向描述 + 英文对照 | 词要可拆可组，每类给够选择余地；英文对照覆盖这位大师特有、直译会失效的说法 |
| `motion.md` | 运动语法：节奏、镜头运动、人物动作、环境动态、视频负向 | 写清"这位大师从不用的运动"；没拍过电影的艺术家（画家、摄影师）可以写"如果他拍视频"，但要标明是推演 |

五条硬要求：

- **不放成品范例，也不放带占位符的整段模板。** 模型读到一段写好的描述，就会照着它的句式和意象去写，每张图都长得像那一段。数据包里只放规则、做法和词库，描述每次现写。
- **禁忌清单是最重要的一节。** 风格的辨识度来自"不做什么"。没有禁忌清单的数据包是废的——生图模型会默认往通用审美上跑。
- **气韵落地表必须有。** 把这位大师身上那些虚词（空灵、物哀、疏离、暧昧）逐个翻译成"占画幅几分之几""光从哪来""什么在动"。翻译不出来的虚词就别写进档案。
- **读人定意境路由表必须有。** 这位大师的世界里有哪几种意境？什么样的人配什么意境？每种意境对应的光和色是什么？没有这张表，人物类的需求只能靠拍脑袋选构图，出来的图会是"风格对了但人和画面两张皮"。**多人表要能装下合影里的笑脸**——用户最常拿来的是家人和朋友，不是剧中人。
- **子风格之间要拉得开。** 每个子风格至少在地景、光、色三栏里有两栏和默认不同；拉不开就合并，别为凑数硬拆。

### 4. 注册

在 `SKILL.md` 的大师索引表加一行：代号、中文名、关键词（决定用户说什么话能命中）、数据包路径。

关键词要**写得宽**：既要有大师本名，也要有代表作名、风格标签、题材词。用户很少直呼大师名字，更多说"武侠意境""吉卜力那种""赛博霓虹雨夜"。子风格一列写简称，用户说片名时能对上。

同时把新大师的代表作名补进 `SKILL.md` frontmatter 的 description，否则用户说片名时 skill 可能不会被触发。

## 自检

新数据包做完，拿它跑一遍 A–D 四条工作流各出一段描述，再用同一个题材换两个子风格各出一段（只用来自检，别存进数据包），然后问自己：

1. 把大师名字从描述里拿掉，还认得出是谁吗？
2. 这段描述和另一位大师的同题材描述，差异够大吗？
3. 同一题材的两个子风格版本，把片名拿掉还分得出是哪部吗？
4. 禁忌清单能挡住最容易串味的那个风格吗？（中式古风串日式、吉卜力串迪士尼、王家卫串普通夜景）
5. 拿一张三人合影走 D：表二能给出一个容得下笑脸的意境吗？

五条都过了才算做完。
