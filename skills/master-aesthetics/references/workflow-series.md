# 工作流 E：组图 / 分镜

用户要的不是一张，是**一组**：一组同调的剧照、一个讲故事的分镜、一套海报加剧照、一组社媒九宫格。

E 是叠加在 A–D 之上的一层规则：每一张图本身还按 A、B、C 或 D 写，E 只管**这一组怎么像同一部片、怎么有节奏**。

## 先分清是哪一种

| 类型 | 用户说法 | 一致的是什么 | 变的是什么 |
|---|---|---|---|
| **同调组图** | "来一组""出四张不同的""九宫格" | 子风格、介质、光色块逐字一致 | 场景、范式、景别 |
| **故事分镜** | "讲一个故事""分镜""连环画""从出发到对决" | 子风格、介质、角色卡、光色基准 | 景别按节奏走，光色可以随剧情时间推进 |
| **真人一组** | "把这几张家庭照都拍成胡金铨的" | 光色块逐字一致 | 每张走 D，各自锁各自的人 |

## 步骤

### 1. 定一套"片子设定"，整组共用

写在最前面，交付时也放在最前面：

```
【片子设定】
子风格：<子风格> · <介质>
时代处理：<档>（有照片时）
光色基准：<光线段 + 色彩段 + 质感段，一字不改地用在每一张>
角色卡：<每个角色一行：年龄感、服装形制和颜色、发式、随身物>
```

**光色基准逐字复用**，这是一组图像同一部片的唯一办法。改一个字，模型就会给出另一种调子。

**角色卡每张都写全**，别写"同前"——生图模型没有跨图记忆。

故事分镜里光色要随时间推进（清晨出发 → 黄昏对决）时，先把每个时段的光色各写一版，同一时段内的几张逐字一致。

### 2. 排景别节奏

全是中景的一组图看起来会很平。按胡金铨的习惯排：

| 位置 | 景别 | 常用范式 | 作用 |
|---|---|---|---|
| 开头 | 大远景定场 | 七式 手卷横摇 / 五式 画中之框 | 先给天地，人还很小 |
| 中段 | 中景关系 | 二、四、九、十式 | 交代谁和谁、在哪 |
| 紧张处 | 局部特写 | 不用范式，见下面 | 眼神、按刀的手、斗笠边、脚下的石阶 |
| 高潮 | 动作或对峙 | 三、六、十一式 | 骤动，或一触即发 |
| 收尾 | 回到远景 | 一式 / 七式 | 人走出画面，只剩山和雾 |

4 张：定场 → 关系 → 局部 → 收尾。
6–8 张：在关系和收尾之间插局部与高潮，局部特写最多占三分之一。

**局部特写**是胡金铨剪辑里的"锣鼓点"：手指搭上刀柄、斗笠下抬起的眼睛、踏在石阶上的布鞋。拍局部不拍整张脸，所以不违反"主体居中特写"的禁忌。写的时候照样交代光和前景。

### 3. 人数一致

整组的人物名单在角色卡里定死。**某一张里出现的人，必须在角色卡上**；角色卡上没有的人不出现（铁律 4）。

故事需要新角色时，先问用户，加进角色卡，再出图。

### 4. 角色跨图一致

- **虚构角色**：先单独出一张"定妆照"（八式亮相，全身，服装看得清），用户认可后，后面每张都把它当角色参考图。
- **真人**：每张都用**原照**当参考，**不用**定妆照或前一张生成图（铁律 5：每转一手脸就漂一点）。

### 5. 分镜的介质

用户要"分镜""故事板"时，问一句要哪种：

- **手绘分镜**（`variants.md` 介质表）：快、便宜，只看构图和节奏，适合先定方案。
- **胶片剧照**：直接出成片效果。

没表态时先出手绘分镜，方案定了再按同样的构图换成剧照介质。

## 交付格式

```
【片子设定】
<上面那四行>

【第 1 张】<景别> · <范式> — <这一张在节奏里的作用>
<画面描述：按 A/B/C 的七段式，或 D 的四块结构；光色段直接贴光色基准>

【第 2 张】……

【负向描述】<整组共用一份；单张需要额外加的，在那一张后面单列>

【建议画幅】<整组统一>，<理由>
```

社媒九宫格例外：九张拼在一起看，画幅统一 1:1，中间那张放最有辨识度的一张（通常是五式或八式）。
