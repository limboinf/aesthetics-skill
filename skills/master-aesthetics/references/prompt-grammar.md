# 画面描述语法：七段式

所有大师、所有工作流共用这一套组装结构。目的是让生图模型拿到的信息**有顺序、无歧义、不打架**。

## 为什么是这个顺序

生图模型对 prompt 前段的权重明显更高。所以顺序按"丢了就不是这张图"排：主体 > 构图 > 空间 > 光 > 色 > 质感 > 气韵。气韵放最后，是因为它最虚，权重低也无所谓——真正让气韵落地的是前面六段的具体做法。

## 七段

### 1. 主体（谁/什么，在干什么，什么状态）
写**可见的形态**，不写心理。人数、朝向、动作瞬间、衣着形制、随身物。
- ✗ 一位孤独的侠客陷入沉思
- ✓ 一名素白长衫的年轻女子侧身立于岩上，斗笠压至眉际，右手虚按腰间刀柄，衣带被风横向吹起

**人数以用户给的为准，一个都不多。** 用户说一个人就写一个人，给一张单人照就是一个人。画面显得空是构图和光的问题，不是人不够的问题——用留白、雾、前景遮挡去填，不要加人。（见 SKILL.md 铁律 4）

### 2. 构图（机位 + 景别 + 主体位置 + 视线引导 + 留白）
明确说出构图法的名字（三分、对角线、框架、三角……），再说主体落在画面的哪一格、占多大比例、画面哪块是空的。
- ✓ 三分构图，人物置于画面右侧三分线上，只占画幅约六分之一，左侧三分之二留给山体与雾气

**控制主体占比要三样一起写**（实测：只写分数，模型不听，尤其在有人脸参考图的时候）：

| 写法 | 例子 | 单独用有效吗 |
|---|---|---|
| 分数 | 占画幅高度约三分之一 | ✗ |
| 景别 | 全身入画，头顶到脚底完整可见 | ✓ 模型最听这个 |
| 画内参照物 | 人物高度不超过身旁岩石的两倍 | ✓ |

要人物极小（≤1/8）时再补一句定性反向指令："这是一张风景画，人物是点景，不是肖像。"

### 3. 空间层次（前中后景 + 纵深 + 遮挡）
至少交代两层，最好三层。这是"有电影感"和"像贴图"的分水岭。
- ✓ 前景是虚焦的深色松枝压住画面左上角，中景是人物与岩石，远景是被雾切断的山脊

### 4. 光线（光源 + 方向 + 质感 + 反差）
说清光从哪来、硬还是软、反差高还是低、有没有特殊光效（逆光边缘、光柱、反光）。
- ✓ 侧逆光，太阳在画面外偏左上方，透过林隙形成可见光柱，整体低反差，暗部不死黑，人物边缘有一圈冷白轮廓光

### 5. 色彩（整体色调 + 主色 + 对比关系 + 饱和度）
给出 2–3 个主色 + 1 个点睛色，并说明饱和度水平。
- ✓ 整体青灰与米白的低饱和色调，岩石偏冷灰，衣物是未漂白的本白，唯一的高纯度色是远处一点赭红，面积不超过画面百分之三

### 6. 质感与介质（胶片 / 镜头 / 年代感 / 材质）
让画面有物理来源，避开"数码干净感"。
- ✓ 七十年代彩色胶片质感，细腻颗粒，轻微色偏，高光柔和滚落，无锐化

### 7. 气韵（一句意境，收尾）
一句就够，且必须是前六段已经支撑起来的那个感觉。
- ✓ 画面安静，人在山中极小，言有尽而意无穷

## 组装规则

- **连成一段**，别用条目。生图模型对连贯长句的理解比对项目符号好。
- **300–500 字**。少于 300 字风格立不住，多于 500 字后段会被稀释。
- **同一元素只说一次**。重复描述会让模型加权，容易把配角画成主角。
- **数量词要具体**："三人""占六分之一""不超过百分之三"，比"一些""少量"有效得多。
- **动词优先于形容词**。"雾从谷底涌上来，切断山脊"好过"雾气氤氲的山景"。

## 意境一致性（最容易翻车的地方）

七段不是七个独立的槽位，是**同一个意境的七次表达**。意境在第 3 步就定好了（见 SKILL.md 执行顺序），七段全部服从它。

只要有一段跑偏，整张图就散——最常见的情况是构图和主体写得很准，光色却按"好看"去写，出来的图技术上没错，但没有味道。

### 每段怎么服从意境

| 段 | 怎么呼应意境 |
|---|---|
| 1 主体 | 姿态与视线方向和意境同向：收敛的意境 → 内收的手势、目光不直视；扩张的意境 → 肢体外展、正面迎向镜头 |
| 2 构图 | **留白留在哪**由意境定：孤峙 → 留白在人物视线前方（有去路）；困局 → 留白被四周挤压掉 |
| 3 空间 | 前景遮挡的轻重：出世 → 轻、透、可穿过；压迫 → 重、实、堵住 |
| 4 光 | **意境的主要载体**。反差高低、方向、软硬，是意境最直接的物理形式 |
| 5 色 | **意境的主要载体**。冷暖倾向、饱和度、点睛色的面积 |
| 6 质感 | 颗粒与柔化程度：苍茫 → 颗粒重、对比粗；空灵 → 高光柔化、边界软 |
| 7 气韵 | 一句话，且必须是前六段已经支撑起来的那个感觉 |

### 检查方法：单段盲测

写完后，**遮住其他段，只读第 4 段和第 5 段**，问自己：能猜出意境吗？

猜不出来，说明光和色在打酱油——这张图会是"构图对了但没气"。回去重写这两段，不要动构图。

### 同一范式，两种意境

同样是一式三分留白，构图段几乎一字不差，光色段一换，意境完全是两回事：

| | 孤峙 | 空寂 |
|---|---|---|
| 构图段 | 人在右三分线，左侧三分之二留白 | 人在右三分线，左侧三分之二留白 |
| 光段 | 低反差漫射晨光，脸三分之二沉在阴影里，只有左颊一道冷白侧光 | 雾中侧逆光，人物边缘一圈柔光，背景虚化成光斑，暗部整体抬起 |
| 色段 | 冷青灰与墨黑，唯一暖色是腰带暗红，不超过画面 1/20 | 素白与雾白，几乎无彩，远山泛极淡的青 |
| 主体占比 | 1/3，看得清神情 | 1/8，只剩一个白色的形 |
| 结果 | 一个握权者独自站在山上 | 一个人几乎融进了山里 |

**构图是骨架，光色才是气。** 意境拉不开，十有八九是光色两段没干活。

## 负向描述

固定三类拼起来：

1. **大师禁忌**（从 `masters/<代号>/profile.md` 的禁忌清单抄）
2. **通用画质负向**：多余手指、肢体畸变、文字水印、五官崩坏、塑料感皮肤、过度锐化、HDR 泛滥
3. **本次特有**：这张图里特别容易串味的东西（比如拍寺庙容易串日式，就写"日式建筑、鸟居、樱花"）

## 画幅

| 画幅 | 什么时候用 |
|---|---|
| 2.35:1 | 山水横卷、群像对峙、要强调横向展开 |
| 16:9 | 通用场景，安全默认 |
| 4:3 | 单人特写、室内、要压迫感 |
| 9:16 | 竖幅立轴感、瀑布/古树/高塔等纵向主体，或用户明确要手机端 |

## 一图多出的一致性

同一组图要像出自同一部片：**第 4 段（光线）和第 5 段（色彩）逐字保持一致**，只改第 1、2、3 段。第 6 段也别动。
