# 工作流 A：纯生成

用户只给了文字意图，从零造一张大师风格的画面。

## 前置：把模糊意图钉成四个要素

用户说的常常是"来张胡金铨风格的图"。这不够。缺哪个补哪个，**一次最多问两个问题**，其余的自己按大师的典型母题定，定完在交付时说明"我替你定了 X，要换告诉我"。

| 要素 | 缺了会怎样 | 没答案时怎么办 |
|---|---|---|
| **场景** | 最致命，等于没题 | 从 `profile.md` 的"场景母题"里挑最有代表性的一个 |
| **人物** | 画面没有落点 | 按所选镜头范式的默认人数来（独行/三人/群像对峙） |
| **时刻** | 光线定不下来 | 选该大师最标志性的光（胡金铨=晨雾侧逆光） |
| **意境** | 最影响成片气质：光和色全从它来 | 有具体人物 → 按 `profile.md` 的「读人定意境」路由表推；纯风景 → 按场景的自然意境走（山道=苍茫，客栈=紧绷，古刹=空寂） |

## 步骤

### 1. 选镜头范式
读 `masters/<代号>/shots.md`，按"场景 + 人数 + 情绪"匹配。匹配到两个都合适时，把两个都摆出来让用户选，各写一句话区别——**这一步让用户参与，最终图的满意度最高**。

### 2. 查禁忌
在写之前先看一眼 `profile.md` 的禁忌清单。用户的要求里如果已经埋了雷（"胡金铨风格的清朝格格"——胡金铨是明代考据），现在就指出来，别等画完。

### 3. 按七段式写
读 `references/prompt-grammar.md`，词汇从 `masters/<代号>/prompt-kit.md` 的词库取。

镜头范式里给的模板是骨架，**必须按用户的具体题材改写**，不能原样交付——原样交付等于没干活。

### 4. 自检三问
- 这段描述去掉大师名字，还能看出是谁的风格吗？看不出 → 构图段和光线段不够狠，重写。
- 有没有哪个形容词后面没跟具体做法？有 → 删掉或补具体。
- 禁忌清单逐条过，有没有漏进来的？

### 5. 交付
按 SKILL.md 的输出格式。额外附一句：**这张图的可变量是什么**（比如"把人物换成两人、或者把时刻改成黄昏，都还在风格内"），方便用户迭代。

## 出组图时

用户要一组（比如 4 张讲一个故事）时：

1. 先定一条**光线与色彩基准**（七段式的第 4、5 段），四张图逐字复用。
2. 每张换不同的镜头范式，且**景别要拉开**：远景定场 → 中景关系 → 近景对峙 → 远景收尾。全是中景的一组图看起来会很平。
3. 主体的服装描述四张都要写全，别写"同前"——生图模型没有跨图记忆。
