# 工作流 A：纯生成

用户只给了文字意图，从零造一张大师风格的画面。

## 前置：把模糊意图钉成六个要素

用户说的常常是"来张胡金铨风格的图"。这不够。缺哪个补哪个，**一次最多问两个问题**，其余的自己按大师的典型母题定，定完在交付时说明"我替你定了 X，要换告诉我"。

| 要素 | 缺了会怎样 | 没答案时怎么办 |
|---|---|---|
| **场景** | 最致命，等于没题 | 从 `profile.md` 的"场景母题"里挑最有代表性的一个 |
| **子风格** | 世界定不下来：时代、地景、色域都悬着 | 从场景推（竹林→侠女，客栈对峙→龙门，海边→忠烈图），推不出来就用侠女。见 `variants.md`「怎么挑」 |
| **人物** | 画面没有落点 | 用户没说人 → 默认一个人或无人，**不替用户安排群像**。用户说了"一群""两队"才用群像范式 |
| **时刻** | 光线定不下来 | 选子风格最标志性的光（侠女=晨雾侧逆光，龙门=午后硬光，山中传奇=秋雾）。时刻表见 `profile.md`「时刻与天气」 |
| **意境** | 最影响成片气质：光和色全从它来 | 用户描述了人物气质 → 按 `profile.md` 表一推；纯风景 → 按表三从场景定 |
| **用途** | 画幅和主体大小会错 | 默认电影剧照；提到头像、壁纸、海报时读 `use-cases.md` |

## 步骤

### 1. 选镜头范式
读 `masters/<代号>/shots.md`，先按人数筛，再按"场景 + 意境 + 用途"匹配。匹配到两个都合适时，把两个都摆出来让用户选，各写一句话区别——**这一步让用户参与，最终图的满意度最高**。

### 2. 查禁忌
在写之前先看一眼 `profile.md` 的禁忌清单和子风格的「禁忌增减」。用户的要求里如果已经埋了雷（"胡金铨风格的清朝格格"——胡金铨的考据不到清代；"龙门客栈里的竹林"——两部片的世界混了），现在就指出来，给一个改法，别等画完。

### 3. 按七段式写
读 `references/prompt-grammar.md`，词汇从 `masters/<代号>/prompt-kit.md` 的词库取。

范式只给要点，描述要从用户的题材出发现写。同一个范式连着用几次，主体、场景、前景遮挡物都要换，别每张都是同一套意象。

### 4. 自检三问
- 这段描述去掉大师名字，还能看出是谁的风格吗？看不出 → 构图段和光线段不够狠，重写。
- 有没有哪个形容词后面没跟具体做法？有 → 删掉或补具体。
- 禁忌清单逐条过，有没有漏进来的？

### 5. 交付
按 SKILL.md 的输出格式。额外附一句：**这张图的可变量是什么**（哪些要素换掉之后还在风格内），方便用户迭代。

## 出组图、出视频时

- 要一组（同调组图、讲故事的分镜）→ 每张按本流程写，整组的一致和节奏按 `workflow-series.md`。
- 要视频 → 先按本流程写一张关键帧，再按 `workflow-video.md` 加运动。
