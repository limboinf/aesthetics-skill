# 工作流 D：真人照片重拍

用户给一张**真实照片**，照片里有他在乎的人（家人、孩子、朋友、自己），要"用某某大师的风格重拍一遍"。

这是四条流程里最容易让用户失望的一条。风格再对，只要照片里的人看着不像本人，这张图就废了。

## 第一原则：人物一致性压倒一切

优先级从高到低：

1. **像本人**：脸、发型、体型、年龄感
2. **姿态不变**：姿势、头部角度、视线、表情、手势、人和人之间的相对位置
3. **人数不变**：要保留的人一个不少；路人一个都不能多
4. 大师风格：取景、光、色、质感、服装、场景

第 4 条和前 3 条冲突时，让第 4 条。风格不够浓可以再调，人不像了用户就不要这张图了。

> 实测教训（2026-09-23）：给三个孩子的照片重拍，第一版为了"构图好看"让孩子们换了站位和姿势，还在生成图上连改了两轮。风格很到位，用户的评价是"跟原图里的人不太像"。改成只参考原照、姿态全部锁住以后，一次就像了。

## 和 B、C 的区别

| | B 风格重构 | C 人物融入 | **D 真人照片重拍** |
|---|---|---|---|
| 原图里的人 | 不重要，或者没有人 | 要保住脸，姿态可以重摆 | 脸和姿态都要保住 |
| 构图 | 可以推倒重来 | 重新设计 | 只允许调取景，人不动 |
| 典型需求 | "把这张风景照改成胡金铨风格" | "把我放进胡金铨的竹林里" | "把孩子们这张合影拍成胡金铨的电影剧照" |

用户给的是真人照片，又没说要换姿势，默认走 D。

## 步骤

### 1. 读原图，列两张清单

**人物清单**：哪些人要保留，哪些是要删掉的路人。**要保留的人数，就是输出画面里的人数。**用户说"这三个小朋友"，照片里的大人就算路人，要在提示词里点名删掉，比如"包括小女孩身后的大人和她的手臂"。只写"删掉路人"不够，模型会留下半截手臂或一双鞋。

**姿态清单**：给每个保留的人写一行，内容是位置、姿势、头部角度、视线、表情、手势。这张清单会原样写进提示词的锁定块。例：

> 前景左侧的长发大女孩坐着，身体朝右，仰头向上看，双手交握搭在膝上；中间的小女孩坐在石栏上，双腿垂下，脸微侧，安静地斜看向画面左侧；后方的男孩趴在石栏上，张嘴笑着看向镜头。

### 2. 定意境

按 `workflow-portrait.md` 步骤 2.1 的四轴读人，再查 `masters/<代号>/profile.md` 的路由表，定出意境。

在 D 流程里，意境**只决定光、色、场景和服装**，不能拿来改姿态。照片里的孩子在比 V，就算意境是"孤峙"，也不能让他把手放下来。

### 3. 做取景诊断

对照大师的构图法则，说清原图的取景哪里不对，再从**允许清单**里挑改法：

| 允许（为美学主动做） | 禁止 |
|---|---|
| 拉远镜头、把画面往两侧或上方延展，补出环境 | 改姿势、改表情、改视线、改手势 |
| 换画幅，比如 4:3 改 16:9，让模型去延展画面 | 调换人物站位，或把某人挪到前后别的位置 |
| 调整人物在画面里的占比和落点（压到三分线上） | 改脸、发型、发量、体型比例 |
| 加前景遮挡，做出前、中、后三层 | 加人 |
| 服装换成大师世界里的样式，**保留原衣服的颜色和明暗** | 美颜、磨皮、把脸画得更精致或更成熟 |
| 换场景、换光色、删现代物件和路人 | |

诊断示例：

- 人物挤在画面中间，占了一大半 → 拉远，改横幅，人压到右侧三分之二，左侧留给古松和远山
- 原图本来就是前大后小的纵深 → 保留纵深，往视线方向延展，给仰望的方向留出空间

**拉远有代价**：人在画面里越小，脸上的像素越少，模型就越难保住长相。经验值（单次实测）：每张要认得出的脸，高度不低于画面高度的十分之一。想要"人在山中极小"那种效果，D 流程给不了，改走 A 或 C，并跟用户说清楚脸会认不出来。

### 4. 写提示词：四块结构

D 是**编辑任务**，不是从零描述一张新图，所以不用 `prompt-grammar.md` 的七段式一段写到底。要按块写，让模型分清哪些是锁死的、哪些可以动。七段式里的构图、空间、光、色、质感，分别放进第 3 块和第 4 块。

```
参考图是一张真实照片。请以它为基础重新拍一张电影剧照。

【必须保持】
- 身份：画面里的<N 个人>就是参考图里的这<N 个人>本人。脸型、五官、眼型、肤色、
  发型、发量和年龄感都与照片一致，不重新设计，不美颜，不把脸画得更精致或更成熟，脸上干净。
- 姿态：<第 1 步的姿态清单，逐人一行>。三人之间的相对位置和前后关系与照片一致。
- 人数：画面里只有这<N 个人>。<点名要删的路人>一律删掉。

【允许为美学做的调整】
- 重新取景：可以拉远镜头、把画面向两侧和上方延展，补出完整环境，让人物的占比和位置
  更好看。延展部分与原图的透视、光线连贯。
- 空间层次：可以加前景遮挡，让画面有前、中、后三层。
- 替换：衣服换成<时代>装束，保留原衣服的颜色和明暗；场景换成下文的环境；
  现代物件、文字、商标全部去掉。

【这一张的取景】
<第 3 步的诊断：原图哪里不好 → 怎么改；主体压在哪、占多大、哪里留白、前中后景各是什么>

【统一光色（<大师>风格）】
<光线 + 色彩 + 质感，从 profile.md 和 prompt-kit.md 取词。同一组图这一块逐字一致>

【不要出现】
<大师禁忌> + 路人、第 N+1 个人、换脸、五官变形、改变姿态、改变表情、年龄改变、
美颜磨皮、大眼瘦脸、脸上污渍、多余手指、畸形手、文字、水印
```

写身份时，**用短而硬的锁定句，不要逐条描写五官**。写成"方脸、浓眉、单眼皮"这种长描述，模型会照着描述**造一个长得差不多的新人**，反而更不像。长相交给参考图去定，文字只负责告诉模型"就是这几个人，别改"。

### 5. 出图参数

| 项 | 建议 | 原因 |
|---|---|---|
| 参考图 | **只放原照一张** | 不用把脸单独裁出来。风格参考图（`gallery/`）也别放，里面的人脸会混进来 |
| 质量档 | **高档**（GPT-Image 系用 `high`） | 人像要的是像本人。便宜档能出图，但保脸的余量太小 |
| 模型 | 编辑精度优先的那一档（例：apimart 上用 `gpt-image-2.5-sunburst`） | 这是编辑任务，不是自由创作 |
| 分辨率 | 2k | 画面拉远以后，脸需要足够的像素 |
| 画幅 | 要延展画面就比原图更宽（4:3 → 16:9） | 画幅变宽，模型就会往两侧补画面 |

参考命令（apimart-image-gen）：

```bash
bun <apimart-image-gen>/scripts/main.ts --promptfiles prompt.md \
  --ref 原照.jpg --image out.png --ar 16:9 --resolution 2k \
  --quality high --model sunburst
```

### 6. 自检：把原图和出图并排看

逐人对照三件事：**脸像不像、姿态对不对、人数对不对**。

哪一项不对，都**回到原照重新生成**，不要拿生成图当底图接着改（见翻车 1）。回退时的顺序：

1. 先把取景改动收小一点（少拉远一些、延展少一些），让脸大一点
2. 还不像，就把锁定块写得更硬
3. 别去加五官描述（见第 4 步）

**局部小瑕疵**，比如脸上一个污点、一根多出来的手指，别为它重新生成整张图。用本地修图工具只修那一块（OpenCV `inpaint` 或任何修复画笔都行），重新生成反而可能把脸改掉。

## 翻车清单

1. **在生成图上连着改**：每改一轮，脸就离本人远一点，改到第二轮就能明显看出来。**永远回到原照重来。**
2. **为了构图重摆姿态**：脸的角度一变，本人就认不出来了。构图不满意，就动取景，别动人。
3. **长篇五官描述**：模型会造出一个相似的新人。
4. **"夕阳"两个字把整片天染成橙色**：写了"夕阳"，模型默认铺大面积橙红。要冷色调为主时，写明"暖色只出现在夕阳附近和人物轮廓上，面积不超过画面五分之一"。
5. **路人删不干净**：只写"删掉路人"不够，要点名到具体部位（"身后大人的手臂""画面左侧那双鞋"）。
6. **服装串味**：深色交领配系带，容易画成日式作务衣。明代题材要写"宽袖、束布腰带"，并把"作务衣、和服"写进负向。

## 交付格式

```
【人物清单】保留 <N> 人：<谁>；删除：<哪些路人>

【意境】<意境词> — <从谁的什么神情姿态读出来>

【取景诊断】<原图的问题> → <怎么改>；人脸估计占画面高度 <比例>

【提示词】
<四块结构全文>

【出图参数】参考图：原照 1 张 / 质量：高 / 画幅：<比例>，<为什么>
```
