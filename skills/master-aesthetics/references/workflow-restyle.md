# 工作流 B：参考图风格重构

用户给了一张图（自己拍的风景、旅行照、街景、室内、别处找的、AI 生成的），要"按大师美学优化"。

> 图里有真人，而且用户要认得出这些人（家人、孩子、合影）→ 走 **D 真人照片重拍**（`workflow-reshoot.md`）。B 会动构图、重写整段描述，保不住人的长相和姿态。

核心动作不是"套滤镜"，是**诊断 → 决定保留什么 → 决定改什么 → 重写描述**。

## 步骤

### 1. 读图，写出现状四行
先看图，用四行把现状说清楚（这一步给用户看，让他确认你没看错）：

```
主体：<画面里有什么，谁在哪>
构图：<现在是什么构图，主体占多大，重心在哪>
光线：<光从哪来，硬软，反差>
色彩：<主色，饱和度水平>
```

### 1.5 原图里有人？先读人定意境

参考图里有具体人物时，不要跳过这一步——**照片里那个人的神情，就是这张图该有的意境**。按 `references/workflow-portrait.md` 步骤 2.1 的四轴读法读出气质，查 `profile.md` 的「读人定意境」路由表（单人表一，多人表二），得到意境词。

后面的"改造"档全部服从这个意境：原图的光和色要改成什么样，不是看大师"一般怎么打光"，而是看这个意境要什么光。

纯风景照跳过这步，按 `profile.md` 表三从场景定意境。

### 1.6 定子风格和时代处理

**子风格**：从原图的场景推（竹林→侠女，海边→忠烈图，寺院→空山灵雨，秋山→山中传奇，荒地烈日→龙门），见 `variants.md`「怎么挑」。

**时代处理**（`SKILL.md` 有三档定义）决定下一步"删除"档删多少：

| 档 | 原图里的现代建筑 / 他国寺院 | 现代服装 | 游客、电线、招牌 |
|---|---|---|---|
| 古装化 | 换成子风格时代的样式 | 换 | 删 |
| 半转译 | **保留** | 按用户意思 | 删 |
| 现代保留 | 保留 | 保留 | 删杂乱的，留必要的 |

旅行照默认问一句："要保留这个地方本来的样子，还是变成片子里的场景？"

### 2. 做差值：保留 / 改造 / 删除

对照 `masters/<代号>/profile.md`，把参考图的每个要素归到三档：

| 档 | 判断标准 | 例子 |
|---|---|---|
| **保留** | 用户要的核心内容，且不与大师风格冲突 | 人物身份、主要动作、场景类型 |
| **改造** | 内容留着，但表达方式换成大师的 | 居中构图 → 三分构图；正午顶光 → 晨雾侧逆光；高饱和 → 低饱和 |
| **删除** | 大师不会让它出现在画面里（按时代处理档定删多少） | 现代物件、霓虹色、过曝白墙、塑料质感、游客 |

**没有"新增"这一档。** 三档里只有保留、改造、删除——原图里没有的人和事，不要放进来。原图一个人，出图就一个人；缺的气氛用雾、留白、前景遮挡和光去补。（见 SKILL.md 铁律 4）

**改造清单要摆给用户看**，一条一行，这是这条流程最有价值的输出——用户从这里学到大师到底在做什么。

### 3. 定重构强度

问一句（或按用户语气判断），给三档：

| 强度 | 保留什么 | 适合 |
|---|---|---|
| **轻** | 构图、主体位置、人物姿态全保留，只换光色质感 | 用户对原图构图满意 |
| **中**（默认） | 保留主体和场景，重新构图 | 绝大多数情况 |
| **重** | 只保留"讲的是什么事"，画面全部重造 | 原图只是个参考意向 |

### 4. 写描述

按 `references/prompt-grammar.md` 七段式写**一段全新的完整描述**，不要写成"把原图的 XX 改成 YY"——生图模型不理解增量指令，它只认完整画面。

两点特殊处理：
- 保留档的要素，描述要**写得更具体**（比原图更精确地描述人物姿态和衣着），防止模型改掉。
- 轻度重构时，第 2 段（构图）要**逐字描述原图的构图**，包括主体在第几分线、占多大比例。

### 5. 交付时额外给一段"垫图建议"

用户手上有原图，多半会走图生图（image-to-image）。附一句参数建议：

| 重构强度 | 重绘幅度建议 | 说明 |
|---|---|---|
| 轻 | 0.3–0.45 | 构图基本不动 |
| 中 | 0.5–0.7 | 构图会变，主体还在 |
| 重 | 0.75+，或者干脆纯文生图 | 原图只当色彩参考 |

具体数值各模型叫法不同（denoise strength / 相似度 / 参考强度），说明"按你的工具里控制'像原图程度'的那个参数换算"。

## 最常见的三种翻车

1. **只改色不改构图** → 出来还是原图套了个滤镜。构图是大师风格的第一辨识特征，必须动。
2. **保留了现代痕迹** → 一根电线杆、一件羽绒服、一块玻璃反光，整张图就塌了。删除档要狠。（半转译、现代保留时保留的是用户要的那部分，不是所有杂物。）
3. **把主体放大** → 用户潜意识想让主体清楚，但很多大师（尤其胡金铨）的特征恰恰是人物极小。要顶住，或者在交付时说明这个取舍，让用户选。
