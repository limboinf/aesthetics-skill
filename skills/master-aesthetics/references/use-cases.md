# 用途适配

同一个意境，做头像和做手机壁纸是两张完全不同的图：画幅、主体大小、留白放在哪，都由**用途**决定。

用途只改这几样：画幅、主体占比、留白 / 留字的位置、范式的首选。**意境、子风格、光色不因用途改。**

用户没说用途 → 按"电影剧照"做（16:9 或 2.35:1），交付时问一句要不要改成别的用途。

## 速查

| 用途 | 画幅 | 主体占比 | 首选范式 | 要点 |
|---|---|---|---|---|
| **电影剧照**（默认） | 2.35:1 / 16:9 | 按意境 | 按意境 | 不用改 |
| **头像** | 1:1 | 脸和肩占画面一半以上 | 八式 近景变体 | 见下 |
| **手机壁纸 / 锁屏** | 9:16 | 1/8–1/4，压在下三分之一 | 一式 竖版 / 五式 | 上方留给时钟 |
| **电脑壁纸** | 16:9 / 21:9 | 1/8–1/6，偏一侧 | 七式 / 一式 | 中间偏左留给桌面图标 |
| **海报 / 书籍封面** | 2:3 / 3:4 | 1/3–2/3 | 八式 / 五式 | 留片名区，字后期加 |

## 头像

头像会被缩到很小，所以：

- **脸必须清楚**：八式近景变体，胸像以上，脸落在三分线上、不居中
- **轮廓要硬**：侧逆光给脸一圈亮边，缩小以后还能从背景里跳出来
- **背景简单**：一层虚化的环境（雾、竹、山）就够，不放复杂前景
- 圆形裁切时，脸和关键道具（斗笠边、刀柄）都在画面中心的圆里

这是胡金铨风格里最"不胡金铨"的用途（他的人常常小到看不清）。交付时可以说一句：想要更有味道，可以把人缩小，换成社媒配图那种比例。

## 手机壁纸

- 9:16 竖幅，像一幅立轴
- 主体压在下三分之一，**上方 1/3 留空**（天、雾、山壁），时钟和通知放在那里
- 竖向的东西做骨架：古松、竹干、瀑布、悬崖、塔
- 七式手卷横摇不适合，换一式竖版或五式

## 海报 / 封面

- 先定**片名区**：上方三分之一，或一侧竖条。描述里写成"画面上方三分之一是大面积雾白天空，没有任何物体"
- **字后期加**：不让生图模型写片名。用户坚持要模型写字时，只写很短的标题，并提醒可能写错、需要返工
- 可选介质：手绘电影海报（`variants.md`），这时放宽主体占比

## 产品 / 品牌图

茶、酒、香、服饰、文具常被要求"做出胡金铨的感觉"。

- 产品**就是主体**，按 C 的"人物"对待：用户给了产品照，参考图就放产品照，产品的形状、颜色、标志都锁住
- 产品的商标是唯一允许出现的文字，负向里的"文字"改成"除产品标志外的文字"
- 产品放进子风格的世界里：石台、旧木案、竹席、雾中的山石
- 光照意境走，常用侧逆光给产品一圈轮廓，背景压暗
- 主体占比按投放位定：电商主图产品占一半以上（八式产品版：产品偏离中心、低机位、背景留一层环境）；品牌意境图产品可以只占 1/6（一式）
- 不要往画面里加没要求的人（铁律 4）。要"人拿着产品"，先问是谁

## 旅行照重做

用户自己拍的风景、寺院、竹林、古街，要"拍成胡金铨的感觉"。走 B（有认得出的人走 D），先定**时代处理档**：

- 想保留"这是我去过的那个地方" → **半转译**：建筑、地形保留，删游客和现代杂物，光色质感按子风格改
- 想变成片子里的场景 → **古装化**：建筑换成子风格时代的样式
- 京都、首尔等地的寺院和竹林，半转译通常最好：寺院本身留着，不再往里加鸟居、樱花一类新东西。`profile.md`「时代处理」一节有出处

## 宠物

- 走 C，身份锁定句改成"就是参考图里这只动物本身：毛色、花纹、脸型、体型不变"
- 默认**不给宠物穿古装**、不拟人。用户要时照做
- 宠物在胡金铨世界里的位置：客栈门口趴着的猫、山道上跟着的狗、寺院石阶上的猫——是点景，不是道具
- 单只宠物照，画面里就只有这一只，不加主人（铁律 4）

## 空间 / 建筑 / 情绪板

室内设计、民宿、茶室、展陈要胡金铨的气质：

- 无人，按 `profile.md` 表三定意境
- 十式（室内）或五式（门洞框景），重点写光：门窗天光的方向、光柱、暗角
- 材料写具体：旧木、夯土、竹席、粗麻、石灰墙、青砖
- 用户要的是"现代空间里的这种气质"时，时代处理用**现代保留**
