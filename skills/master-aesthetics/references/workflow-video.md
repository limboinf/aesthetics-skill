# 工作流 F：视频镜头

用户要的是动起来的画面：一段几秒的视频、一个动态海报、一组镜头。产出交给视频模型（可灵、即梦 / Seedance、海螺、Veo、Sora、Runway、Vidu 等）。

F 也是叠加层：**先按 A–D 定一张静帧，再给它加运动**。运动规则查 `masters/<代号>/motion.md`。

## 第零条：优先图生视频

文生视频的风格很难稳住，一段 5 秒的视频里，前一秒是胡金铨、后一秒就成了仙侠剧。所以默认流程是：

1. 按 A/B/C/D 写一张**关键帧**的描述，先出图
2. 用户认可这张图后，把它当**首帧**，写运动提示词，走图生视频

用户坚持文生视频时也可以，但要提醒：风格漂移的概率高，提示词里的光色段要写满。

## 步骤

### 1. 定关键帧

按用户手里有什么走 A/B/C/D。关键帧在选范式时多想一步：**这一帧接下来会怎么动？**

- 要人入画、出画 → 范式留出画边的空间（一式、七式）
- 要腾跃 → 十一式，关键帧可以选起跳前，也可以选最高点
- 要缓推揭示 → 五式（从框外推向框内）
- 什么都不想动，只要氛围 → 任何范式都行，靠环境动态

### 2. 选运动

查 `motion.md`，从三样里各挑一个：

- **一种镜头运动**（固定、横摇、缓推、跟升，选一个，不叠）
- **主体动作**（最多两拍，按时间排）
- **环境动态**（1–2 样）

节奏按时长：5 秒装一个节拍，8–10 秒走"静 → 动 → 定"。

### 3. 写视频提示词

视频提示词比静帧短，**80–200 字**。按块写：

```
【首帧】使用参考图作为首帧（文生视频时：贴关键帧描述的精简版）。

【镜头】<一种运动，方向，速度>

【动作】<第一拍>，然后<第二拍>。<最后停在什么状态>

【环境】<1–2 样环境动态>

【光色】<与关键帧一致：一句光 + 一句色 + 一句质感，不要换说法>

【不要】<motion.md 的视频负向 + 子风格负向里最要紧的几条>
```

光色段和关键帧**用同一套说法**，换个同义词，模型都可能把调子拉走。

### 4. 有真人时

真人视频比真人静帧更容易丢脸：每一帧都可能漂一点。

- 动作幅度压小：转头不超过 45 度，不大幅转身，不让脸被遮住再露出来
- 首帧用 D 流程出的图，且那张图里脸要够大（高度不低于画面的十分之一）
- 【动作】块前面加一句锁定："人物的脸、发型、体型在整段视频里保持不变，不变成别人"
- 多人时写明"人数始终是 N 个，不增不减"

### 5. 一组镜头

用户要剪成一支片子（多段视频）时，按 `workflow-series.md` 先排分镜和片子设定，再给每一段写视频提示词。每段的【光色】块逐字一致。

## 交付格式

```
【关键帧】
<按 A/B/C/D 的交付格式，只有一张时可省略意境和范式说明>

【视频提示词】
<上面的块结构>

【参数建议】时长 <5 / 8 / 10 秒> / 画幅 <与关键帧一致> / 运动强度 <低 / 中>，<一句话理由>
```

运动强度默认**低**。胡金铨的"动"多半是环境在动，人物动的那一下很短。
