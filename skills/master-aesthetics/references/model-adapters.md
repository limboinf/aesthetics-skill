# 下游适配：按生图 / 生视频工具改写

本 skill 的默认产出是**中文自然语言描述**（七段式 / 四块结构），直接适合理解长句的模型。用户说了具体工具、或要英文时，按这里改写。

改写只改**语言、长度、负向的放法、参数**。意境、范式、光色的决定一个不动。

> 各家的参数名和能力变得很快。下面写的是写法上的规律；具体参数以用户手里那个版本的文档为准。不确定时就别给参数，只给描述。

## 按工具分四类

| 类型 | 典型工具 | 语言 | 长度 | 负向怎么放 |
|---|---|---|---|---|
| **长句理解型** | GPT-Image、nano banana（Gemini 图像）、即梦、MiniMax、可图、通义万相 | 中文 | 300–500 字 | 多数没有负向框 → 改成正向约束（见下） |
| **英文自然语言型** | Flux、Imagen、Ideogram | 英文 | 80–200 词 | Flux 等没有负向框 → 改成正向约束 |
| **短语 + 参数型** | Midjourney | 英文 | 40–80 词，前重后轻 | `--no` 后面跟少量名词 |
| **标签型** | Stable Diffusion / SDXL 及其衍生 | 英文标签 | 30–60 个标签 | 有独立负向框，整段放进去 |
| **视频** | 可灵、即梦 / Seedance、海螺、Veo、Sora、Runway、Vidu | 中英都行 | 80–200 字 | 写进【不要】块；有负向框的放进去 |

用户没说工具 → 按长句理解型交付。

## 没有负向框时：负向改正向

很多模型没有负向输入。这时把负向清单原样贴在描述末尾（"不要出现和服、鸟居、樱花……"）效果不稳，**提到一个东西，有时反而会把它画出来**。

做法：

1. **能改正向的改正向**：
   - "不要高饱和" → "整体低饱和，颜色像褪了一层"
   - "不要居中特写" → "人物在右侧三分线上，全身入画"
   - "不要现代物件" → "画面里的一切都是木、石、竹、麻、土做的"
2. **改不了、又最容易出错的**，留 3–6 条，用一句"画面里没有……"收在最后。优先留：人数约束（铁律 4，实测必须写）、最容易串的那个相邻风格的标志物、身份锁定相关的几条
3. 其余的删掉

## 英文改写

- **不逐句翻译**。按七段的顺序重写成英文短句，主体和构图放最前面
- 胡金铨特有的说法，查 `masters/<代号>/prompt-kit.md` 的「英文对照」，别自己硬翻（"留白"直译出来模型不懂）
- **数量词保留**：英文模型对 "one-eighth of the frame"、"lower third" 的反应和中文一样好
- 片名和导演名：可以在末尾加一句 "in the visual style of a 1970s King Hu wuxia film"，但**不能靠它**。只写名字、不写具体做法，模型会给出泛泛的"古装武侠"。名字是锦上添花，七段式才是主体

## Midjourney

- 结构：主体 + 构图 → 光 → 色 → 质感 → 介质，用逗号分隔的短语或短句；最重要的放前 20 个词
- 画幅：`--ar 12:5`（约等于 2.35:1）、`--ar 16:9`、`--ar 9:16`、`--ar 2:3`
- 胶片剧照质感建议加 `--style raw`，减少默认的"精修感"
- 负向用 `--no`，只放 5–10 个名词（kimono, neon, pink, 3d render, text）
- 有风格参考图、人物参考图的参数，各版本名字不同（风格参考、角色 / 全能参考），按用户的版本给。真人照片的规矩照铁律 5：只放原照

## Stable Diffusion / SDXL

- 正向写成标签，按重要性排序，最重要的几个可以加权，例如 `(tiny figure in vast misty landscape:1.3)`
- 胶片、构图、光的标签一样要有，不能只堆"中国风、武侠"
- 负向框直接放 `prompt-kit.md` 的英文负向
- 图生图的重绘幅度见 B、C 流程

## GPT-Image / nano banana / 即梦这类

- 直接用中文七段式，不用改写
- 编辑类任务（B 轻度、C、D）选编辑精度优先的模型，人像用高质量档（铁律 5）
- 多图输入的工具，参考图只放必要的那张（真人原照 / 产品照），别加风格参考图

## 视频模型

按 `workflow-video.md` 的块结构写。各家共同的规律：

- 图生视频比文生视频稳得多
- 运动写**一种**镜头运动 + 最多两拍动作，写多了全糊
- 时长 5 秒最稳；10 秒要给出明确的"静 → 动 → 定"
- 有"运动强度"之类的参数时，默认调低
