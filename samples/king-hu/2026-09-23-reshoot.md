# 实跑记录 · 胡金铨 / 真人照片重拍（D 流程的由来）

2026-09-23。素材是两张夜景街拍，里面有三个孩子（另有大人和路人）。需求是"把这三个小朋友拍成胡金铨风格"。

**链路**：`apimart-image-gen` → `gpt-image-2.5-flare` / `gpt-image-2.5-sunburst`，2k。

## 迭代过程

| 轮次 | 做法 | 结果 |
|---|---|---|
| v1 | 两张原照一起当参考，按 C 流程写七段式，**重新设计站位和姿态**（三角群像、对角行进） | 风格到位。孩子被重摆了姿态，脸也有点漂 |
| v2 | 拿 v1 当底图接着改（手势、额头污点、男孩身高） | 每改一轮脸就漂一点；额头污点改了两轮都去不掉，最后用 OpenCV inpaint 在本地修掉 |
| v2.5 | 回到原照，**原构图原姿态**，只换服装和场景，另加三张裁出来的脸部特写 | 很像本人。但构图只是原照，没有做美学上的优化 |
| **v3** | 只放**原照一张**，提示词分四块（锁定 / 允许 / 取景 / 光色），允许拉宽画面、重新取景 | 保住了人，也有了胡金铨的构图。每张 $0.022，比 v2.5 便宜，因为参考图只剩一张 |

## 校准结论（已写回 skill）

1. **人物一致性压倒风格** → SKILL.md 铁律 5、`workflow-reshoot.md` 第一原则
2. **不要在生成图上连着改**，每次都回到原照 → 铁律 5、D 流程翻车 1
3. **姿态锁住，只改取景** → D 流程第 3 步：允许清单和禁止清单
4. **身份用短锁定句，不写五官** → 铁律 5、C 流程第 4 步
5. **人像用高质量档**，推翻了 2026-09-22 记录里"medium 就够"的结论。用户要的是像，不是能出图 → C 流程第 5 步、D 流程第 5 步
6. **"夕阳"会把整片天染橙** → `prompt-kit.md` 色彩词库
7. **深色交领会串成日式作务衣** → `prompt-kit.md` 服装词库

## v3 提示词全文（第二张：前景大女孩仰望）

参考命令：`--ref 原照.jpg --ar 16:9 --resolution 2k --quality high --model sunburst`
（本次实跑用的是 medium，结论 5 是事后定下的。）

```
参考图是一张真实照片。请以它为基础重新拍一张电影剧照。

【必须保持】
- 身份：画面里的三个孩子就是参考图里的这三个孩子本人。脸型、五官、眼型、肤色、发型、发量和年龄感都与照片一致，不重新设计，不美颜，不把脸画得更精致或更成熟，脸上干净。
- 姿态：每个孩子的姿势、头部角度、视线方向、表情、手势，以及三人之间的相对位置和前后关系，都与照片一致。
- 人数：画面里只有这三个孩子，其他大人和路人一律删掉。

【允许为美学做的调整】
- 重新取景：可以把镜头拉远、把画面向两侧和上方延展，补出完整的环境，让人物在画面里的占比和位置更好看（例如压到三分线上，留出天空和山的空间）。延展出来的部分必须和原图的透视、光线连贯。
- 空间层次：可以加前景遮挡（松枝、石栏一角），让画面有前、中、后三层。
- 替换：衣服换成明代孩童装束，但保留原衣服的颜色和明暗；场景换成下文描述的环境；现代物件、文字、商标全部去掉。

【这一张的场景与取景】
原照是前景大、后景小的纵深构图：前景左侧是仰头的长发大女孩，中景石栏上坐着小女孩，后景石栏边趴着笑的男孩。保留这种三层纵深，同时把画面向右延展成横向宽画幅：大女孩仍在画面左侧三分之一，占比比原照略小，头顶上方留出一点天空；右侧延展出来的空间留给雾中层层后退的山和夕阳，让她仰望的方向有空间。石栏换成风化的青灰色中式石栏板和望柱，下方的水池换成山间一汪静水，倒映着夕阳。

【统一光色（胡金铨电影风格）】
黄昏时分。背景是层层后退的雾青色山脊，越远越淡，只剩轮廓，山谷间浮着薄雾。一轮低悬的淡橘色夕阳挂在远山上方，被雾柔化成光晕，只有靠近夕阳的天空泛极淡的浅橘，其余是雾青。夕阳从人物后方斜射过来，给头发和肩膀边缘镶一圈暖金色轮廓光；脸部处在柔和的雾青色环境光里，清楚可见，低反差，暗部不死黑。整体以雾青和灰蓝为主，暖色只出现在夕阳和人物轮廓上，低饱和。七十年代彩色胶片质感，细腻颗粒，高光柔和滚落，边缘柔和，无锐化，没有数码HDR感。明式服装：交领、宽袖、束布腰带、布鞋，不要日式作务衣或和服式样。

【不要出现】成年人、路人、第四个人、现代建筑、招牌、文字、商标、国旗、霓虹、运动鞋、日式服装、和服、作务衣、日式屋檐、火烧云、高饱和、粉色、紫色、HDR、过度锐化、3D渲染感、磨皮美颜、大眼瘦脸、换脸、五官变形、改变姿态、改变表情、年龄改变、脸上污渍、多余手指、畸形手、水印。
```
