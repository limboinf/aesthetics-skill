## 四条校准（已写回 skill）

1. **凭空加人是最严重的失败模式** → SKILL.md 铁律 4、workflow-portrait 第零条、shots.md 人数标注、profile.md 禁忌清单"内容越界"
   单人题材被套进群像范式，构图越漂亮，错得越离谱。用户要的是风格，不是剧情。
2. **占比只写分数没用** → prompt-grammar 第 2 段
   必须"分数 + 景别 + 画内参照物"三样一起写。模型拿到人脸参考图会本能放大主体。
3. **身份保持比预期容易** → workflow-portrait 步骤 5
   medium 档 + 单张参考图就稳得住脸。不要预先建议用户升质量档，注意力该放在占比和加人上。
   > ⚠️ 2026-09-23 推翻：人像默认用高质量档。见 `2026-09-23-reshoot.md`。
4. **树林要写树种和杂乱度** → prompt-kit 场景词库
   只写"密集的垂直树干"，模型默认画排列整齐的北美针叶林。
